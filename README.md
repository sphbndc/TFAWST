# Pointline POS

Pointline is a four-page Laravel POS directory with customer and staff records stored in MySQL or SQLite through Eloquent.

The current Laravel project is in `TFA6/`. It includes migrations, a seeder with five customers and five users, and an SQL export for InfinityFree.

See [`TFA6/README.md`](TFA6/README.md) for local setup, database import, and hosting instructions.
